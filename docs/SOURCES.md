# Sources and Standards Basis

## Interpretation constraints

- Ссылки не делают конкретный product stack обязательным.
- Версии и feature status implementation stack MUST проверяться при проектировании конкретной системы.
- DOA не заменяет NIST, ISO, IEC, medical, automotive, aviation или robotics safety requirements.
