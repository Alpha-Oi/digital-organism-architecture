# DOA Principles

## P1. Contract before metaphor

Биологический термин допускается только при наличии ответственности, интерфейса, протокола, telemetry и failure policy.

## P2. Homeostasis before autonomy

Автономность допустима лишь внутри измеримых target ranges, resource budgets и authority boundaries.

## P3. Organism over model

Модель — сменный когнитивный компонент. Identity, policy, memory, resource control и recovery принадлежат организму.

## P4. Compartmentalize failure and privilege

Каждая клетка имеет minimal capability, quota, lease, inbox/outbox и реальную isolation boundary.

## P5. Desired state is not observed state

Signed genome задаёт ожидаемое; sensors и telemetry сообщают фактическое; reconciler устраняет отклонение без сокрытия uncertainty.

## P6. Adaptation is governed change

Learning, prompt updates, skill promotion и routing changes проходят evaluation, approval policy, staged rollout и rollback.

## P7. Provenance is part of data

Данные без источника, времени, integrity и classification не допускаются в trusted memory или decision path.

## P8. Reflexes are deterministic

Validation, permissions, arithmetic, emergency stop и известные remediations не делегируются LLM, если их можно выразить детерминированно.

## P9. Defense is layered and tolerant

Barrier, receptors, innate immunity, adaptive immunity, quarantine и repair независимы. Tolerance явна, ограничена и отзываема.

## P10. Observability closes the loop

Метрика без decision/action path — диагностика, а не гомеостаз. Action без correlated evidence — неуправляемая мутация.

## P11. Failure is a first-class state

`UNKNOWN`, `SUSPECT`, `DEGRADED`, `ISOLATED` и `REPAIRING` моделируются явно; отсутствие ошибки не равно здоровью.

## P12. Safe death is a capability

Компонент должен уметь прекращать работу, отзывать полномочия, сохранять разрешённые evidence и освобождать ресурсы без cascade failure.

## P13. Diversity without incompatibility

Разные models/providers/stacks уменьшают correlated risk, но контракты, observability и policy semantics остаются едиными.

## P14. Ecology matters

Организм существует среди пользователей, сервисов, партнёров и других агентов. Federation требует identity, treaty/policy, quotas, provenance и revocation.

## P15. Conformance is evidence, not branding

Заявление о соответствии указывает profile, exclusions, verified checks и дату.

## P16. Growth is bounded

Рост числа клеток, глубины делегирования, репликации и потребления ресурсов ограничен genome и может быть прекращён authority вне растущего компонента.

## P17. Identity outlives components

Identity организма сохраняется при замене любых компонентов подписанной цепочкой continuity; завершённая сущность не воскресает из устаревшего состояния.

## P18. Learning is not evolution

Обучение меняет только declared adaptive parameters; изменение genome — отдельный, более строгий контур.
