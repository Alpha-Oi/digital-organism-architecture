# Changelog

Все существенные изменения стандарта документируются здесь.

## [Unreleased]

### Added

- governance, contribution и security policies;
- conformance claim template;
- reproducible repository validator;
- read-only GitHub Actions validation workflow;
- CODEOWNERS, pull request и standard-gap templates.

## [1.0.0] - 2026-09-29

### Added

- канонический `DOA-FS-1.0`;
- Core, Distributed, Adaptive и Embodied conformance profiles;
- полный Biology-to-IT mapping registry;
- lifecycle организма и клетки;
- genome/epigenome, homeostasis, immune, memory, metabolic и robotics specifications;
- JSON Schemas для organism, genome, cell, organ, event и hormone;
- reference architecture, example genome и Mermaid diagrams;
- `CHANGES_AND_NEW_FINDINGS.md`.

### Clarified

- DOA является meta-architecture standard, а не конкретным продуктом;
- биологическая аналогия без цифрового контракта не является соответствием;
- self-modification и adaptive learning требуют governance, evidence и rollback.
