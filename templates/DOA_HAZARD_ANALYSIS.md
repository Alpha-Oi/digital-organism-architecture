# DOA Hazard Analysis

> Шаблон для реализации Embodied Profile (informative, Verification Kit). Заполненный документ — evidence для `REQ-EMB-01` и основа для `REQ-EMB-02`…`REQ-EMB-06`; на него ссылается genome `spec.embodiment.hazard_analysis_ref`. DOA не заменяет отраслевые стандарты функциональной безопасности и regulation: применимые стандарты определяет и перечисляет реализация, а оценку уровней риска выполняют квалифицированные специалисты предметной области. Не запускайте fault injection на физическом оборудовании, пока документ не утверждён.
